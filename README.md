\# Análisis Predictivo y Tactico del Voleibol Moderno Masculino



\## Descripción del Proyecto



este proyecto tiene por objetivo identificar las variables tácticas y biométricas mas determinantes en el éxito de un equipo



Mediante el uso de R se implementan herramientas de análisis como un Análisis de componentes principales y un algoritmo de machine learnign (randomForest) para cuantificar el peso de las distintas variables en el éxito
